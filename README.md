# MiniMQ

A Lightweight Message Queue System Implemented in C++.

## 1. Introduction

MiniMQ is a lightweight message queue system implemented in C++,
inspired by RabbitMQ.

The project aims to implement message production,
message consumption, network communication and message persistence.

## 2. Technology Stack

- Language: C++
- Network: TCP / epoll
- Network Framework: Muduo
- Serialization: Protobuf
- Database: SQLite3
- Unit Testing: Google Test
- Build System: CMake / Makefile

## 3. Development Environment

- Ubuntu 22.04 LTS
- GCC / G++
- Boost
- Protobuf 3.20.2
- Muduo
- SQLite3
- GTest
